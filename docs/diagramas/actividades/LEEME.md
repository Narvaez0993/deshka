# Diagramas de actividades del MVP

Un diagrama por cada historia del Release 1, en notación de actividades de UML, con
carriles Usuario, App y API (y Worker en HU-47).

- `hu-NN.drawio`: el diagrama, editable en draw.io (escritorio o web).
- `hu-NN.svg`: la imagen.
- `enlaces.md`: enlace editable de cada diagrama (abre en app.diagrams.net sin cuenta).
- `generar.py`: genera los tres a partir de la definición de cada flujo
  (`python3 generar.py`; la imagen necesita draw.io de escritorio).

En la entrega 3 se sumó a HU-03, HU-13, HU-14, HU-25 y HU-29 el flujo alternativo que
implementa la app.
